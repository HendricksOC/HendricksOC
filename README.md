## 👨‍💻 Sobre Mim

Sou um desenvolvedor apaixonado pelo ecossistema **Back-end**, atualmente cursando Ciência da Computação na Gran Faculdade. Meu foco principal é a construção de APIs RESTful escaláveis, arquitetura de microsserviços e a criação de sistemas robustos e eficientes.

- 🔭 Desenvolvendo aplicações com foco em performance utilizando **Java e Spring Boot** (Data JPA, Web MVC).
- 🌱 Explorando a integração de Inteligência Artificial com sistemas.
- 🧪 Forte defensor da qualidade de software, aplicando Clean Code e TDD com **JUnit 5, Mockito e AssertJ**, além de testes de carga em APIs com **k6**.
